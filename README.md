# Сүйен — starter page

A static concept page for a future family support platform in Kazakhstan.

Open `index.html` in a browser to view it. The page uses plain HTML, CSS, and JavaScript, with Russian and Kazakh copy. There is no build step or backend yet.

The name and product integrations are still under discussion. The page does not provide accounts, bookings, telehealth, payments, or eGov/OSMS connectivity.
